# as-courage Website Starter

Diese Dateien gehören direkt in:

C:\Users\Kunde\Projekte\as-courage-website

Die Bilddateien müssen in diesem Ordner liegen:

C:\Users\Kunde\Projekte\as-courage-website\Bilder

Erwartete Bildnamen:
- Startbild.jpg
- Logo 1997.jpg
- Logo as-courage transparent.png

Start:
1. ZIP entpacken.
2. index.html und styles.css in den Ordner C:\Users\Kunde\Projekte\as-courage-website kopieren.
3. Die Datei index.html im Browser öffnen.

Hinweis:
Die Unterseiten impressum.html und datenschutz.html sind noch Platzhalter-Links. Sie werden später angelegt.
